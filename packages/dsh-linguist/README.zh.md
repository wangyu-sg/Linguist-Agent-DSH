# Linguist Agent · 游戏本地化

在 DeepSeek Harness 中组织游戏本地化项目，完成翻译、双语审校和校对。DSH 管理会话、模型、权限和通用工具；Linguist Agent 提供项目资源、CAT 编辑、工作副本和本地化工作流程。

## 功能概览

- **CAT 工作台**：对照原文与译文编辑，完整显示行内运行时标签代码，使用不可见字符、术语提示、数字与变量检查和修改差异辅助核对。Phrase MXLIFF 支持原生粗体、斜体、下划线及其平面组合。默认富文本显示，可切换格式码；编辑时先选译文，再用 B／I／U 或 ⌘/Ctrl+B、I、U 添加或取消样式。工具条操作仅改草稿，撤销、重做同时恢复文字和选区。富文本内复制的选区带平衡的原生格式码，格式码视图复制所选原始字符；未知或未配对格式保留字面并提示，上标和下标暂不可用。
- **任务组**按来稿或版本组织批次。点项目名称进入，可在组内导入或新建会话。同一原稿跨组导入后分别编辑、导出；移动已有批次会保留译文和修订。
- **项目资料**：从主页项目卡片直接进入，查看、添加、替换、移除原件及编辑用途、适用范围，读取错误直接显示。可维护项目共用资料和组专用资料，或指定只在本组替代一份继承资料。备份会保留这些归属和上传文件；工作区直接登记的外部原件需另行保管。与 Agent 使用同一资料库，替换失败保留旧版，无需先打开 CAT。
- **参考资源**：项目 TM／TB、规则、例句、Query 和反馈供普通问答及三种工作方式共用。普通查词使用文字与 TM／TB 匹配；按含义找例句时使用语义检索，计算进度分批保存。正式审校材料直接附带相关记录和出处；字段少也可用，不编造确认状态，变更资料才重新解析。TM／TB 沿用原有匹配。
- **审校与 QA**：独立审校覆盖完整源译文，兼顾连续语言含义与备注要求、术语和关联文案。工作副本在后台准备成组 TM／TB、原表附加字段和规则；材料完整不等于已经审过。保留锁定、稳定句段 ID、修订冲突检查和实际执行记录。
- **三种工作方式**：CAT、工作副本和浏览器均可委派译者、审校或校对；直接对话也可讨论本地化问题，无需先导入项目。未绑定项目时可为本次文件指定 TM／TB。
- **图片上下文**：本批 XLSX／PPTX 的内嵌图片和位置可随审校材料提供，并在工作区缓存；仍须实际看图。PPTX 的文字和版式应结合原幻灯片查看。

## 开始使用

1. 在侧栏打开 **Linguist**。可从 **添加工作区 → LA 工作区 · 本地化项目** 创建工作区和项目，也可在已有 DSH 工作区中创建或打开项目。
2. 说明任务并提供资料。正式任务未选定工作方式时，LA 先问一次是否用 CAT；已有选择就沿用，普通咨询不需要选择。选择 CAT 后准备受管理的副本、关联资料并检查段落、标签和锁定。表格核对工作表与列映射，Phrase split 同时提供 master；也可手动导入。
3. 在 Linguist 主页选择工作区、岗位和工作方式，点击项目卡片的 **新建 LA 会话**；会话自动关联该项目和工作区。下方 **项目会话** 随工作区筛选，点击 **打开会话** 继续旧任务。进入会话后说明任务范围、风格要求与交付目标。
4. 在 CAT 中核对源文、当前译文、必要上下文和 QA，再保存、确认或导出。生成建议、应用修改、审校完成、导出文件和客户平台提交是不同操作。

## 数据与保存

已保存的项目、术语、翻译记忆和修订保存在配置的数据目录。更新插件继续使用已有的数据目录、安装标识和配置；原稿、项目数据与导出的交付物需要分别管理和备份。

**重载、更新或退出之前，请先保存编辑器中尚未保存的内容。** 本地存储不等于完全离线：模型和浏览器任务按实际连接的服务、宿主权限及项目要求执行。

读取快照和分片进度随原会话保存，热更新或重启后可接续，实际修改仍检查原文和译文版本。由 1.3.4 或更早版本升级时，请在任务保存停稳后重启一次 DSH，使已有会话移除旧的额外工具结果裁剪；原会话保留。由 1.3.5 升级可直接热应用。

## 兼容与限制

- 当前适配基线为 **DSH 0.2.2-rc.3**；开发与检查平台为 macOS Apple Silicon，本次构建的原生安装与加载需在 DSH 中确认，其他系统和宿主版本尚未验证。
- 单文件接收上限为 **1 GiB**。接收限额不保证任意格式或大型文件的解析性能，格式要求与检查结果以实际导入流程为准。
- 浏览器任务需要配套的 **官方 BrowserSkill CLI／MCP、daemon 和配套 Chrome 扩展**连接正常；CAT 和工作副本不要求浏览器连接。
- CAT、线上材料和工作副本共用的语义关联需要本机 MemSearch Python ONNX 环境和已缓存的 `gpahal/bge-m3-onnx-int8`。自动成组提供相关原文、当前译文与上下文供独立审校，不把相似当成错误。向量与关联结果按项目缓存在本机，不写入会话记忆、不自动下载或调用云端；环境不可用时明确标记。改译文不重算向量，改原文只补算变化内容。
- 文件锁定随副本读取；平台导出缺失锁定时，需要完整平台快照按稳定 key 与当前源译文核对后补入，不能仅凭显示行号推断。锁定段保持只读。
- QA 与文件检查不等于游戏内 LQA。导出不会自动提交客户平台，也不会代替人工确认任务范围与交付结果。

## 维护与许可

在 DSH 官方插件管理器中安装、更新和启用；以宿主返回的应用结果及重载提示为准。详情页、项目工作台和会话岗位各有用途：这里说明能力与使用方法，项目操作仍在 Linguist 工作台中完成。

插件许可：**AGPL-3.0-only**。当前安装版本以 DSH 插件管理器显示为准。

全局显示与检索偏好、模型环境检查及语义缓存管理位于 **DSH 设置 → Linguist**。项目语言、QA、标签和交付设置沿用各项目原有配置。线上任务按整批导出或平台快照提供关联，不切换工作方式；平台 TM／TB 与 Comments 仍须核对。不新增逐条查询或逐组回执。
