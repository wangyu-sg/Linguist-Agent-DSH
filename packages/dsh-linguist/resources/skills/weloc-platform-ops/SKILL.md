# WeLoc 网页作业

通过 DSH Shell 与官方 `ego-browser` 技能操作当前已登录的 WeLoc 网页工作台。本技能处理平台资料采集、原稿与 XLIFF 导出取材、译文回填、批注留评及 QA/确认状态核对；专业质量仍遵循工作区项目规则与 LA 共同标准。

> **适用条件**：本技能与参考文档中的结构、字段、状态码和保存机制源自对特定现网版本（Vue 3 / Quasar / Pinia / Tiptap ProseMirror）的技术观察。它们用于解释该观察版本的运行行为，不代表所有 WeLoc 部署或后续版本永久不变；实际作业必须结合当前页面可见控件与渠道类型核对。

## 适用对象与常见任务

- **渠道与入口差异**：WeLoc 存在 `CMSRnd`、`CMSOps`、`TMS` 等不同入口和工作模式；界面结构相似，但文件下载权限与保存触发路径不同。
- **常见任务**：
  1. **只读采集与取材**：查看订单「文件 → 下载原稿」或导出前端 XLIFF 1.2；按 50/100 行硬分页逐页读取原文、当前译文、上下文、长度限制、图片/视频参考、TM/TB 候选及已有评论，整理材料与缺口清单。
  2. **获授权回填与留评**：在激活后的真实编辑器中修改批准句段，按当前渠道对应的保存路径确保持久化并重读验证；按本批授权在差异处发表或维护评论，保护已有批注引用。
  3. **QA 与确认**：区分文件、句段与导出报告的 QA 口径，映射回稳定句段核对；按授权处理句段确认，不擅自推进客户流程阶段。

## 关键特性与作业边界

- **静态展示与编辑态分离**：未激活的原文/译文为 `v-highlight` 静态节点，改静态 HTML 无效；必须进入 `TargetText` 挂载的 `EditorView` 后操作，并留意编辑重绘导致焦点与选区变化。
- **保存语义依渠道而异**：该观察版本中，**CMS 模式失焦仅存本地草稿**，服务端落盘出现在 Confirm、QA 等明确路径（关页/组件卸载不可靠），且 40 秒轮询有覆盖未提交草稿的风险；**TMS 模式失焦走服务端保存**。
- **切段与切页签异步残留**：TM/TB/评论面板异步刷新，切段或切页签后正文可能短暂保留上一段或上一页签的内容；采集前先核对当前段 ID 与面板实际标题。
- **严格区分操作后果**：本地保存、服务端保存、运行 QA、句段确认与最终提交是不同动作；不得为了保存草稿擅自点击确认或完成任务，也不写入内部状态字段或调用私有写接口。
