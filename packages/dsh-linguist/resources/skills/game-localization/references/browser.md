# 网页和在线作业

用 DSH Shell 加载官方 ego-browser 技能，执行 `ego-browser skill` 获取本机操作说明。按当前项目规则、批次目标和用户授权选择操作。需登录时由用户在浏览器完成。

正式批次通过 `linguist_prepare_project` 确定是否使用 CAT。已有批次沿用原选择，本地文件、CAT 和浏览器可以配合。先从本地稿进入 CAT 的批次，后续接网页时可同时传原 `batchId` 和同批平台 `batch` 身份。
