# Phrase 编辑器结构与句段定位

> **观察范围说明**：以下结构与组件细节综合自 2026-11-20 对 Phrase Web Editor（构建参数 `26.23.11`，Vue 3.5.43 / Pinia / TanStack Virtual / Quill 2.0.3）的现场观测与已有作业实践，仅用于理解机制与现场定位；实际选择器与控件应以当前页面 DOM/无障碍树为准，不将未验证的下一代设计假设视为现网协议。

## 1. 页面承载与跨源 iframe

- 任务页外层（`cloud.memsource.com`）主体主要由占满视口的跨源 `iframe` 承载，真实编辑器运行在 `editor.memsource.com` 子文档中。
- 页眉、主区工具栏、筛选栏、双语工作表、底部上下文注释/文内预览以及右侧八个辅助面板均在编辑器子文档内。
- 当顶层页面无障碍树或控件不足时，应通过当前浏览器工具支持的 frame 切换或文档上下文机制直接检视编辑器子文档，不要自己编造 URL 参数来“强制启用编辑”。

## 2. 作业、流程阶段、合开视图与稳定段 ID

- **稳定身份与视图序号分离**：句段拥有各自所属的 **Job（作业）**、**流程阶段（Workflow Step）** 与 **稳定段 ID**（在序列化模型与 DOM/导出中分别以段 ID / `data-id` / unit-segment ID 体现），而表格最左侧序号列（`displayPosition`）只是当前视图顺序。
- **合开多作业**：在 Phrase 项目页勾选多个已获授权的作业并一起打开，会在同一编辑器内按文件拼接并连续编号。进入后第一时间核对包含的各个 Job 及其所处流程步骤；绑定记录和回写必须关联到 `Job + 流程阶段 + 稳定段 ID`，绝不能仅凭显示行号区分句段。
- **工作范围区分**：当前过滤视图结果、屏幕可见窗口与全量 Job 范围并不相同；在未清除筛选条件前，不得把当前可见行数当作全批总数。

## 3. 动态行高虚拟列表与数据窗口

- 双语网格采用 `TanStack Virtual` 动态行高虚拟滚动：
  - 观测版本估算初始行高约 `30px`、`overscan=20`，挂载后在动画帧动态测量高度，外层占位容器维持总高度。实测 384 行样本中同时仅约 26 行挂载 DOM、其中几行真正进入视窗。
  - 渲染窗口外另有数据加载窗口：滚动变化经约 `150ms` 防抖，向两端扩展约 `50` 项后按需加载；跳段目标尚未加载时，编辑器会先滚动到索引，待目标挂载后再设置源/译侧焦点与光标。
- **对作业的影响**：
  1. 滚动、筛选、折叠底部面板或行高变化后，原先采集的 DOM 节点和屏幕坐标可能立刻失效，不可跨重渲染盲复用节点引用。
  2. 全量采集页面信息时须随列表连续滚动并按稳定段 ID 去重；有权导出时，优先通过编辑器「文档 → 导出 → 双语 MXLIFF 文档」获取完整双语对照与确认/锁定字段。

## 4. 静态展示节点与实际活动输入节点

- **展示态与输入态完全分离**：在任务打开的默认展示态下，双语表正文（原文列与未激活译文列）由大量静态 `span` 节点组成（长句单侧可超过百个 `span`，包含文本片段、内联标签内容、标签编号、不可见空格与回车符装饰、拼写提示），实测 `contenteditable` 数量为 `0`。
- **实际活动输入**：
  - 主双语句段激活编辑时，会在当前选中行挂载原生输入节点（观测版使用 `input.twe-main-input` 配合自绘光标与 `InputHandler` 处理输入和 IME 组合事件，另针对 Safari 做了组合提交顺序兼容）。
  - 评论/备注输入框属于另一套独立的富文本路径（`TweQuillTextarea`，基于 Quill 2.0.3）。
- **发现提示与聚焦检查**：
  - 在所观察编辑器中，渲染行曾使用 `.segment-row`、`.twe_source`、`.twe_target` 和选中行 `.twe-main-input`，均只作现场发现提示，使用前必须先核对当前页面的真实结构。
  - 译文格可见不代表输入已激活，点击可能仅把该行滚入视窗或选中内部某个标签。应点击文本片段后，核实活动输入确实归属目标 Job、稳定段 ID 与源文本再发送按键，将按键作用域限制在该输入节点而非全局文本框。
  - 当无障碍树仅返回根节点且页面状态未变化时，不要死循环重复 Observe，可使用当前浏览器技能允许的受限现场读取方式核对行身份、Source、Target 与可编辑性。

## 5. 筛选定位与导出互操作边界

- **使用筛选跳转的正确步骤**：
  1. 若全文含内联标签导致整句搜不到，改用不被标签打断的连续纯文本片段筛选；支持大小写、Key、上下文和标签条件（无正则筛选框同样受字符串长度限制）。
  2. 找到目标后，**清除筛选**，等待全表行身份和布局稳定后再重新定位目标行并聚焦编辑。已有实测表明，在实时筛选状态下直接修改容易出现行身份漂移或未识别行问题。
- **原生双语导出边界**：
  - **MXLIFF**：桌面/网页原生双语交换格式，保留 Job UID、unit/segment ID、确认状态、锁定与标签结构，适合作为回填前底稿核对、确认前后对照以及终态验收依据。注意编辑器界面呈现的标签编号与 MXLIFF 序列化记法可能不同。
  - **双语 DOCX**：仅在有权限时可下载和导回同一 Job；锁定行改动导回时会被忽略。不要将导出成功本身等同于已写回平台或已提交任务。
