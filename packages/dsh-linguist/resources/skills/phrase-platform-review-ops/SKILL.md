# Phrase 网页作业

使用官方 ego-browser 技能。以本批项目说明、客户资料和批准版本为准。沿用已核实的下载、定位和编辑方法。

用作业、流程阶段和稳定段 ID 对应原文、现译和终稿。合开视图的显示行号用于跳转。编辑时保留原生标签、格式、变量和锁定。按需求读指定 TM、TB、评论与 QA。

保存后按实际结果回读。遇到冲突、超时或重复联动时，核对平台上的实际范围和现译，再决定如何继续。确认、QA 裁定和完成作业各按本批权限执行。
