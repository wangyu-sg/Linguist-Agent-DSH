# Phrase 网页作业

通过 DSH Shell 与官方 `ego-browser` 技能操作当前已登录的 Phrase / Memsource Web Editor。本技能处理平台读取、定位、输入、参考查证、QA 与授权状态流转；专业翻译与审校标准仍遵循工作区项目规则与 LA 共同标准。

## 适用对象与常见任务

- **页面结构**：外层 `cloud.memsource.com` 任务入口以跨源 `iframe` 嵌入 `editor.memsource.com` 编辑器，支持单作业或勾选多个授权作业后合开视图。
- **常见任务**：
  1. **只读资料读取**：采集原文、当前译文、锁定/确认状态、TM/TB、历史译文、其他语言、备注与已有 QA（或导出双语 MXLIFF 供审校与核验）。
  2. **获授权回填与确认**：按本批唯一批准清单写回目标译文，保存并回读核验；按授权执行句段确认或保持项目页 `Accepted` 状态。
  3. **QA 核查与复核**：按声明范围运行或读取 QA，结合指定客户 TM/TB 依据区分真实问题、误报与未决项。

## 关键特性与作业边界

- **虚拟列表与双层身份**：主工作表使用动态行高虚拟滚动，重渲染后旧 DOM 位置可能失效；合开视图显示连续序号，必须把每行映射到所属 **Job + 流程阶段 + 稳定段 ID**。
- **展示态与编辑态分离**：页面 DOM 外观变化不等于编辑器已接收并保存修改。改静态展示 `span` 无效，含原生标签/格式时不得用纯文本剪贴板直接覆盖。
- **参考异步刷新与自匹配**：切段后右侧 CAT 面板异步加载（TM/TB/MT 分开送达），须核对选中段身份与刷新完成再归属；本轮确认后写入 TM 的自匹配不可冒充独立客户依据。
- **保存队列与状态区别**：切段触发单段异步保存队列，`dispatched` 或旧 Saved 图标不代表已持久化；编辑已确认句段可能重置当前阶段确认；句段确认与 Job `Completed` / `Delivered` 是不同操作。
- **不将某一客户要求永久化**：是否保持 `Accepted`、是否允许导出/确认/写入 TM，一律以当前项目与批次授权为准。不调用未公开私有写接口。
