## 2. 核实少量用户事实

在当前工作上下文核对动作、入口、必要依赖、结果位置、限制和验证状态，不新建永久清单。特别检查：

- 分请求上传不等于拆散业务批次；涉及 Phrase 配对的说明与真实行为一致。
- 文件格式分别说明待译导入、原生导出、参考读取与预览；工作副本 JSON 不是原生交付或平台已提交。

## 3. 只改受影响说明

README 面向译者：用途、真实界面、宿主要求、安装、第一次任务、关键限制、求助。内部构建细节放维护者说明。

用新建项目、导入文件、审校译文、检查标签、导出文件等动作描述功能。不讲宿主演变，不用历史编号和施工口号替代产品介绍。

安装步骤使用真实命令、产物和界面。没有公开产物就不虚构下载链接，没有真实截图就不使用模拟图冒充。相同事实只维护一处权威来源，其他页面引用或合并。旧说法失效优先删改，不不断追加例外说明。

纯内部重构不要求修改 README。维护命令变更只更新相关开发说明；发布说明只写用户有意义的变化和升级动作。
