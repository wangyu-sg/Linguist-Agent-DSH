# 自动任务飞书通知

在官方 DSH 的 Linguist 插件配置中设置 `notificationDestinations`。每个目标包含：

| 字段 | 含义 |
| --- | --- |
| `id` | 唯一、稳定的目标 ID |
| `label` | 工作台显示名称 |
| `appId` | 飞书或 Lark 自建应用的 App ID |
| `appSecret` | 应用密钥；DSH 原生设置将此字段标记为 secret，远程读取时脱敏 |
| `chatId` | 已允许该机器人发送消息的聊天 ID |
| `domain` | `feishu` 或 `lark`，默认 `feishu` |

需要在对应平台给机器人配置发送消息的权限，并使其能够访问目标聊天。插件不读取旧 LA 的配置、浏览器登录信息或聊天记录。

在工作台的“运行 → 创建专业定时任务”中勾选目标，选择每次结束、仅正常结束或仅未成功结束。默认不选任何目标。保存后，该任务才会向勾选的聊天发送任务名称、本轮模型输出和执行状态。错误通知仅含结束类型与错误代码，不发送原始供应商错误正文。

改变同一个目标 ID 对应的应用、聊天或平台后，原任务会拒绝发送；需编辑任务重新保存，确认新目标。密钥轮换不改变目标身份。

任务历史显示“已发送”“发送失败”或“发送结果未知”。只有平台返回消息 ID 才记作已发送。发送期间网络中断或进程中断无法证明平台未收到，故不会自动重复发送。通知状态不影响已经提交的 CAT 结果，也不把执行结束当作专业审校、交付或外部平台确认。

## 当前验证范围

合成验证覆盖真实 DSH 设置脱敏、任务目标校验、收件目标冻结、本轮输出范围、重复结束事件、远端回执和发送中断。没有向真实飞书/Lark 聊天发送验证消息；配置、平台权限和真实投递仍需安装环境验证。
