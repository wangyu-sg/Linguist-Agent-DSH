# Linguist 工作台界面规范

2026-09-30。适用于官方 DSH 内的 Linguist 项目页、CAT、工作副本和辅助面板。布局与交互在本文件定案；安装后的真实窗口验收记录放在迁移状态中。

## 版面

- 项目页：24px 页边距、20px 单行标题、同行项目命令。下方依次为项目筛选、紧凑的岗位/工作方式选择、项目列表、可折叠会话列表。每个标题只出现一次。项目行约 76px，会话行约 56px；长名称省略显示并提供完整提示。
- CAT：项目身份与批次/搜索工具栏置顶；批次导航—双语编辑—参考检查器并排。辅助区在下方，统计栏固定在工作台底部。编辑区占剩余空间，各面板内部独立滚动。
- 源文和译文保持等分，沿用旧 LA。窄编辑区改为上下对照。侧栏在窄面板中作为可关闭的覆盖层，不能把编辑列挤到不可读。
- 批次导航右边、参考检查器左边、辅助区上边均有可发现的拖动边界；支持键盘调整、复位和尺寸保存。临时窗口收缩不覆盖用户保存的尺寸。

## 按钮层级

| 类型 | 表现 | 适用动作 |
|---|---|---|
| 当前区域的主要提交 | DSH primary，sm | 新建项目、运行 QA、保存、确认 |
| 普通命令 | DSH outline，sm | 刷新、重试、导入、预览、设置、打开会话 |
| 导航、披露、关闭 | DSH ghost，sm | 项目名称、页签、更多菜单、定位句段、关闭面板、取消弹窗 |

默认按钮 28px；与 32px 输入框同行的图标按钮为 32px。图标提供 Tooltip 和可访问名称。禁用、悬停、焦点继承宿主。不能用全局覆盖把所有按钮变成一种样式。

## 信息与视觉

- 主文本 13–14px，编辑正文 14px / 1.65，元数据 11–12px；继承 DSH 字体。间距以 4、8、12、16、24px 为序。
- 用宿主背景层、细边界和字重区分区域。选中态用中性背景，焦点单独清晰标识；不使用装饰性的彩色左条。错误、QA 严重度、差异仍使用对应语义色。
- 批次文件名保持单行，预览不挤占文件名行。工具栏不用占满屏幕的解释文字；技术详情按需展开。
- 状态栏恢复旧 LA 的源文/译文 **Unicode 字符数**、当前阶段确认进度、非零草稿、当前句段和选区。审校/校对另显示真实决策覆盖及未修改/修正/阻塞数。字符数与进度来自完整批次/项目聚合，不从虚拟列表可见行推算，不把决策覆盖称为交付完成。

## 主题与验收

所有颜色、字体、圆角、焦点、阴影使用固定 DSH SDK 的公开主题 token。遵守该 token 合同的皮肤可以统一换色、字体和圆角；布局由插件负责，不能承诺任意第三方皮肤的额外定制都会自动生效。

本轮必须在实际官方 DSH 安装包中确认：项目页与会话层级、按钮类别、长文件名、三条分隔线的拖动/键盘/复位/重开、底栏字符数与确认/决策口径、宽/窄/短窗口、明暗主题。源码检查和合成测试是工程证据，不能替代视觉验收。
